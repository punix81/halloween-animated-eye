# GIF assets

Place source GIF animations for the project in this folder.

Runtime requirement:
- Copy the GIF you want to play to the root of the microSD card.
- Rename it exactly to `eye.gif`.
- The Arduino sketch restarts `eye.gif` automatically when the last frame is reached.

Recommended format:
- 240 x 240 px
- Animated GIF
- Optimized file size for smooth playback from microSD
